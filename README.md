# inspir Landing

A compact Astro landing page for inspir, the AI-first learning platform.

## Mission

inspir is building AI-first learning tools for students, with the belief that one-to-one tutoring should be accessible, affordable, and radically smarter.

## What This Repository Contains

Single-page Astro landing site for inspir.uk, introducing the new home of inspir, linking to inspirlearning.com, showing student reach, product direction, history, and press-oriented sections.

## Highlights

- Hero and navigation for the public inspir landing page.
- Links to the live learning product.
- Sections for building, platform, history, and press.
- Lightweight static deployment shape.

## Tech Stack

- Astro
- Single-file landing page
- Static favicon assets
- Google Fonts
